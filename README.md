# PoC: Operadores de Comparação em JS (== vs ===)

Projeto demonstrativo para a disciplina de Sistemas para Internet.
O objetivo é provar a importância da **igualdade estrita** e demonstrar como contornar o problema da **comparação de referências** em objetos.

## 🚀 Tecnologias
- JavaScript (ES6+)
- Node.js

## 🧪 O que este código ensina?
1. **Segurança:** Por que usar `===` ao validar senhas evita erros de coerção de tipo.
2. **Conceitos Avançados:** A diferença entre comparar valores primitivos (string, number) e tipos de referência (objects).
3. **Solução:** Implementação de uma função para comparar o conteúdo de dois objetos diferentes.
